Ведическая астрология

Живые расчёты по данным рождения, сидерический зодиак

Бесплатный сервис ведической астрологии (джйотиш): натальная карта, периоды жизни (даши), совместимость по системе Аштакута, разбор домов и сфер жизни, подбор места для релокации — расчёт по вашей точной дате, времени и месту рождения.
